# Rodízio (all-you-can-eat) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a per-person all-you-can-eat "rodízio" mode (two tiers, kid pricing, day-scheduled) where the customer picks it in the menu, included items show €0, and the staff confirms the headcount and invoices at close.

**Architecture:** Rodízio is a **mode of the table session** (not a product). Config lives in `db.settings` key `rodizio`; each product gets a `rodizio_incluido` field; the customer menu adapts to the session mode; `close_table` computes the per-person charge + paid extras + waste fee and emits one Vendus FS. Follows the spec `docs/superpowers/specs/2026-07-22-rodizio-design.md`.

**Tech Stack:** FastAPI + Motor (Mongo), React (CRA/craco + Tailwind + shadcn), Vendus API (FS, `output=escpos`), print-bridge (ESC/POS). Repo `~/dev/pizzaria`, branch `main`.

async def get_rodizio_public():
